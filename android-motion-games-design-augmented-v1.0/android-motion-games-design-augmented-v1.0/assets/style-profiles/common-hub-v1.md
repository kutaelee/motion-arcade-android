- mood: 깨끗하고 친근한 arcade lobby

- palette anchors: cloud white `#F7F5EE`, navy `#19324A`, aqua `#35BFC2`, coral `#FF765E`, gold `#F6C453`
- lighting: upper-left soft, 2-step cel shade
- material: matte plastic/paper cutout, metallic realism 금지
- icon projection: centered 3/4 orthographic

## No-go

- generated text
- game-specific weapon/fish/monster motifs in system settings
