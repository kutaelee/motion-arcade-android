# Style Profile — monster-v1

- profileId: `monster-v1`
- revision: `1`
- status: `LOCK_CANDIDATE`
- internal name: Runestone Expedition
- scope: player classes, monsters, boss, arena, weapon/magic/defense/co-op FX

## Visual DNA

- mood: 용감하고 유쾌한 fantasy expedition, dark horror 금지
- silhouette: chunky armor, broad weapon, horn/ear/wing shape로 적 구분
- outline: dark forest-indigo `#182E38`, 1024px 기준 12~17px
- palette anchors: forest teal `#247F72`, rune amber `#F0A83B`, mage violet `#7655C6`, stone gray `#87959A`, ember coral `#E9604A`, mist cream `#F2F1D8`
- lighting: upper-left warm rune light, magic glow는 color family별 제한
- shading: 3-tone cel + 큰 rune accent
- projection: side-view arena, characters 3/4 side
- character proportion: head 1:4.8, weapons oversized 15%

## Animation language

- melee: body parts rotate + 4~6 key slash FX
- mage charge: V-pose-compatible glow build, pose guide를 가리지 않음
- monster idle: one defining part motion
- boss phase: silhouette/FX 변화, base identity 유지
- ultimate: foreground coverage 35% 이내, 600ms 이상 full-screen flash 금지

## No-go

- photoreal gore/horror
- copyrighted fantasy franchise resemblance
- tiny high-frequency armor detail
- every magic asset with unrelated palette
- UI text baked into rune/banner

## Locked anchor requirements

- Vanguard/Ranger-Mage turnaround
- 3 common + elite monster silhouettes
- boss 3-phase identity sheet
- arena background
- melee/guard/magic/ultimate FX family
